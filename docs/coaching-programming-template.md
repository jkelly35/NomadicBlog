## 9) Load Decision Rules (Simple)
- If performance markers improve >3% and fatigue is manageable: increase load 2.5-5%.
- If markers are flat (+/-2%): keep load, improve execution quality/density.
- If markers drop >3% or movement quality declines: reduce weekly volume 15-20%.
- If finger pain/tendon irritability rises: reduce finger intensity first, keep movement quality sessions.
